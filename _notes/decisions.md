# Decisions

## Mode
Mode A. The user attached the RELL landing (SingleFile save of tryrell.xyz, 19 Oct 2026).
The saved page is the `rell-web` index after its scripts ran, so the port starts from the clean
`rell-web/index.html`, kept here as `reference/rell-index.html`. The save itself is
`reference/rell-landing.html`.

## Landing follows the reference, not the brief's design system (19 Oct 2026)
A first pass rebuilt the landing in the brief's "Obsidian Champagne" dark design. The user
stopped it: keep the original nearly identical, adapt the content, add stock charts, and keep
every style and design choice. So the landing is:

- `index.html`: the reference markup and inline styles, generated by `_notes/port-landing.py`.
  The script changes only words, links, the logo and a few data hooks. Rerun it after editing it.
- `css/template.css`, `css/landing.css`, `js/landing.js`: the reference files. `landing.js`
  changed only in its config binding (now `window.ORA_CONFIG`) and its loader captions.
- `css/landing-ora.css` and `js/landing-ora.js`: everything Ora adds. That covers the stock charts
  in the market card panels, the Coming soon shimmer, the Solana wallet modal drawn like the
  template's sheet, and click fixes.
- Template colors, fonts (Ancizar Serif, TASA Orbiter, Bitcount, Azeret Mono), paintings and motion
  timings are kept as they are. The brief's parameter tweaks (10 to 25 percent) were not applied,
  because the user asked for identical motion.

## Stock charts
Each market card keeps its painting. The price chart sits in the card's right panel, under the
quote. Stock cards draw 24h prices from `api.getMarkets()`, from mock data while `mockMode` is true.
The strategy cards draw a seeded sample path with the buy and sell points that rule would take.

## Logo
`_notes/make-logo.py` builds the lockup from the template's Ancizar Serif as paths, in the same single
ink color as the RELL logo. The mark is an open ring with an orbit dot.

## Fixes over the reference
- The empty "Sculpture Loader" container and the hero sculptures covered the hero Copy button.
  They now let the pointer through. The live RELL page has the same bug.
- Escape in the wallet modal no longer also closes the phone menu underneath.

## App pages follow the RELL app style (20 Oct 2026)
The user chose the RELL app language for forge, leaderboard, agent, me, docs and 404, so they
match the landing. They run on the template app shell, `css/site.css`, `css/app.css` and
`css/docs.css` from rell-web, kept as they are. Ora additions sit in `css/ora-app.css`, and the
modal shared with the landing is in `css/ora-modal.css`.

- Each page opens with the dark painted hero. The paintings are Forge compass, Leaderboard stairs,
  Agent spyglass, My agents hands, Docs compass, and the 404 valley.
- Stats reuse the landing's "at a glance" look: a hairline, a serif number and a mono label.
- Status chips reuse the template's state washes. AI is purple, Running green, Paused amber,
  Not started grey, Buy green, Sell red.
- The brief's dark design files are parked outside the repo: tokens.css, base.css,
  components.css, motion.css and pages.css. So are hero-canvas.js and visuals.js.
- On touch screens, the 36px template buttons get an invisible 44px hit area instead of a resize.

## Brief items not taken, because the landing stays identical
- No separate S6 leaderboard preview or S7 connect AI block on the landing. The board has its
  own page, and the three calls live in Docs and on each AI agent's page.
- No cursor glow, film grain, view transitions or animation parameter tweaks. The reference has
  none of these.

## Open

- `og.png` still needs exporting from `assets/og.svg`.

## Real API wiring (2026-10-20)
- `js/api.js`: errors from ora-api are `{ error: { code, message } }`, so the code and message are read from `data.error`.
- `js/wallet.js`: in real mode the wallet signs the exact single use `message` from `POST /api/auth/nonce`. Demo mode still builds its own message.
- Smoke tested headless against a local ora-api with mock prices, with `js/config.js` rewritten in flight only. The file still has `mockMode: true`.
